# Historical Kavach source

Inactive source variants are grouped by their original checkout. `provenance.json`
records the source commit and exact SHA-256 of each retained file. These files are
not part of the current PRATIRODH package, deployment image or test suite.

Historical dependencies and claims apply only to the original prototype. Current
setup, verification decisions and evidence formats are documented in the main
README. Do not install archived requirements into the current environment.
