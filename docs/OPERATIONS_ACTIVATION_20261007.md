## Input contract

bytes). Sign the payload encoded as ASCII JSON with sorted keys, compact
separators and `ensure_ascii=True`, using `canonical()` in the tool.

Payload fields are `schema` (`pratirodh.operations-attestation.v1`),
`source_sha256`, `issued_at`, `expires_at`, a short accountable `owner` label,
`public_activation` (`DEFERRED`), and `backups`, `signer`, `alerts` controls.
Control field names are defined explicitly in the tool's `boolean_fields` and
`numerical_fields` contract; every control also requires `drill_at` and
`receipt_sha256`. Booleans must be actual JSON booleans; measurements must be
nonnegative integers. Do not place secrets or addresses in these documents.

Each receipt is a JSON object with exactly `schema`
(`pratirodh.operations-drill.v1`), `control` (its control name), `source_sha256`
and `observations`. Observations must exactly match that signed control's fields
except `receipt_sha256`. Preserve the actual receipt bytes as
`<sha256>.json` under the receipt directory. Receipts are operator-controlled
summaries of completed drills, not generated by this preflight from configuration.
Maintain the underlying external execution records separately for reviewer
